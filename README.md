# gard3npt.github.io

Página inicial dos meus projetos: vídeos, ferramentas gratuitas e uma coleção de caricas, todos num só sítio.

**Abrir:** https://gard3npt.github.io/

## Os meus sites

| Site | O que é |
|---|---|
| [AGAJOTA](https://gard3npt.github.io/agajota/) | O meu site principal, com os vídeos do YouTube, as ligações úteis e as redes sociais. |
| [Simulador de Juros](https://gard3npt.github.io/simuladorjuros/) | Compara várias simulações de depósitos a prazo, com TANB e juros compostos. |
| [Calculadora de Juros (Mobile)](https://gard3npt.github.io/calculadorajuros/) | Versão pensada para o telemóvel, com números grandes, instalável como app. |
| [Caricas Metálicas](https://gard3npt.github.io/caricas_metalicas/) | Catálogo e exposição digital da minha coleção de caricas, com galeria de fotos. |
| [SC Lab](https://gard3npt.github.io/sc/) | Hub de ligações úteis e calculadoras para facilitar o dia a dia no Lab. da SC. |

## O que tem a página

- Um cartão por site, para abrir cada projeto com um toque.
- Uma secção **Sobre este espaço**, com a explicação do nome AGAJOTA, que vem das minhas iniciais, H e J, e não é uma empresa.
- A **Política de Privacidade**.
- A secção **Contacto e Suporte**, para perguntas, sugestões ou erros encontrados.
- Ligações para as minhas redes sociais.
- Disponível em português e em inglês.
